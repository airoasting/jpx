# 일본 공시 용어 ↔ 한국(DART) 용어

답을 쓸 때 일본어 원어를 한 번 괄호로 붙이고, 그다음부터는 한국어만 쓴다. 갱신 기준: 답에서 헷갈린 용어가 나오면 여기에 한 줄 추가한다.

## 공시

| 일본 | 읽는 법 | 한국 대응 | 차이 |
|---|---|---|---|
| 決算短信 | 결산단신 | 잠정실적 공시 + 분기보고서 요약 | 거래소 규칙 공시. 회사 연간 예상이 반드시 붙는다. 감사 전 숫자 |
| 有価証券報告書(有報) | 유가증권보고서 | 사업보고서 | 결산 후 3개월 안. 감사 후 확정 숫자 |
| 半期報告書 | 반기보고서 | 반기보고서 | 2024년 4월부터 분기보고서 대신 |
| 四半期報告書 | 분기보고서 | 분기보고서 | **2024년 4월 폐지**. 1·3분기는 단신만 남았다 |
| 適時開示 / TDnet | 적시공시 | 수시공시 / KIND | TDnet 원본은 약 한 달 보관 |
| EDINET | | DART | 금융청 법정공시 시스템 |
| 業績予想の修正 | 업적 예상 수정 | (해당 없음) | 매출 ±10%, 이익 ±30% 이상 바뀌면 공시 의무(거래소 기준) |
| 大量保有報告書 | 대량보유보고서 | 5% 대량보유 보고 | |
| 訂正 / 数値データ訂正 | 정정 / 수치 데이터 정정 | 정정공시 | 수치 데이터 정정이면 XBRL도 새로 나온다 |
| 期中レビューの完了 | 감사인 검토 완료 | (해당 없음) | 같은 숫자를 다시 낸 판. 원본의 '예상 수정' 표시를 지운다 |

## 숫자

| 일본 | 한국 | 메모 |
|---|---|---|
| 売上高 / 売上収益 / 営業収益 | 매출 | IFRS는 売上収益, 토요타는 営業収益 |
| 営業利益 | 영업이익 | IFRS 영업이익에는 감손·매각익이 섞인다 |
| 経常利益 | 경상이익 | J-GAAP에만. 영업이익 + 이자·배당·지분법·환차손익 |
| 経常収益 | 경상수익 | 은행·보험의 매출 자리 |
| 税引前利益 | 세전이익 | IFRS·US GAAP |
| 親会社株主に帰属する当期純利益 | 지배주주 순이익 | 상사·은행은 이것만 예상한다 |
| 会社予想 / 業績予想 | 회사 예상 | 컨센서스가 아님 |
| 期初予想 | 기초 예상 | 전년 연간 단신에 실린 그해 예상 |
| 進捗率 | 진척률 | 누적 ÷ 연간 예상 |
| 中間期 | 상반기 | 2분기 누적 6개월 |
| 2027年3月期 | 2027년 3월기 | 2026.4~2027.3 |
| 百万円未満切捨て / 四捨五入 | 백만 엔 미만 버림 / 반올림 | 3개월치 계산에 ±1백만 엔 오차 |
| 自己株式 | 자기주식 | 취득(한도 공시)과 소각을 가른다 |
| 純資産 / 自己資本 | 순자산 / 자기자본 | J-GAAP 순자산에는 비지배지분·신주예약권이 들어간다. BPS는 자기자본으로 |
| 自己資本比率 | 자기자본비율 | |
| 配当性向 / 総還元性向 | 배당성향 / 총주주환원율 | |
| 資本コストや株価を意識した経営 | 자본비용과 주가를 의식한 경영 | 2023년 도쿄증권거래소 요청. PBR 1배 미만 회사 대응 |
