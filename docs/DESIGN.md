# 일본 상장사 숫자 분석 스킬 `jpx` 설계 (v1)

분류: Prototype. 목표 등급: 실측 3개 기준(J-GAAP, IFRS, US GAAP)과 업종 3곳을 통과하면 9.5점 후보.
위치: AI-Native Market Tools 축. DART(한국), EDGAR(미국)와 같은 줄에 선다.
갱신 기준: 실측에서 틀린 숫자가 나오면 이 문서의 "실패 조건"부터 고친다.

## 1. 한 줄 정의

결산단신(決算短信)을 정확히 읽고, 그 회사가 **스스로 낸 연간 예상을 어떻게 지켜 왔는지**를 숫자로 보여 주는 도구. 키 없이 돈다.

## 2. 왜 따로 만드는가

| 차이 | 한국 DART | 미국 EDGAR | 일본 |
|---|---|---|---|
| 가장 빠른 숫자 | 잠정실적 | 8-K 보도자료 | 決算短信, TDnet. 결산 후 45일 안 |
| 1·3분기 숫자 | 분기보고서 | 10-Q | **2024년 4월 四半期報告書 폐지 뒤 결산단신에만 있다** |
| 분기 숫자 성격 | 3개월 + 누적 | 3개월 + 누적 | **누적만**. 3개월치는 빼서 구한다 |
| 회사 실적 예상 | 드물다 | 콜에서 말로 | **거의 모든 회사가 연간 예상을 공시하고, 수정도 공시한다** |
| 이익 단계 | 영업이익 | Operating income | J-GAAP는 経常利益. IFRS·US GAAP 회사는 없다 |
| 원문 보관 | 영구 | 영구 | TDnet은 약 한 달. **JPX 사본(www2.jpx.co.jp/disc)은 수년** |

## 5. 도구 (v0.1, 6개)

| 도구 | 하는 일 |
|---|---|
| `company_resolve` | 한국어·영어·일본어 이름, 4자리·영숫자 코드 → 회사. 애매하면 후보 |
| `filing_search` | XBRL 공시 목록(단신, 예상 수정, 배당 수정 등). 같은 날 묶음 표시 |
| `fin_tanshin` | 결산단신 한 장: 실적, 전년 동기, 연간 예상, 수정 여부, 배당, 주식 수, 같은 날 공시, 3개월치(직전 누적이 있으면) |
| `fin_guidance` | 한 회계연도의 예상 이력(기초 → 수정 → 실적), 진척률과 과거 같은 시점 진척률, 하반기 암묵 예상, 과거 기초 예상 달성률 |
| `fin_quarters` | 3개월 분기 시계열(누적의 차분). 숫자마다 입력 문서 |
| `market_valuation` | 직전 종가로 PER(예상 EPS), PBR, 배당수익률, 시가총액. ROE를 나란히 |

## 6. 단신 금고

- 위치 `~/.claude/skills/jpx/vault/{code5}/{파일 이름}.zip`과 `.json`(파싱 결과, `parser_version`, `sha256`, `fetched_at`, `source_url`).
- 추가만 한다. 정정 공시는 새 파일로 들어오고, 조회할 때 같은 기간의 최신 정정본을 정본으로 고른다.
- 파서가 바뀌면 zip에서 다시 파싱한다(`parser_version` 비교).

## 7. 계산 규칙과 거부 조건

- **진척률** = 누적 실적 ÷ 같은 문서의 연간 예상. 범위 예상이면 하한·상한 두 값. 예상이 없거나(未定) 0 이하이면 거부.
- **과거 같은 시점 진척률** = 그해 같은 분기 누적 ÷ 그해 연간 **실적**(일본 관행). 정의를 응답에 적는다.
- **하반기 암묵 예상** = 연간 예상 − 상반기 누적. 전년 하반기 실적(전년 연간 − 전년 상반기)과 비교.
- **3개월치** = 이번 누적 − 같은 해 직전 누적. 손익 항목만. 회계기준·연결 범위가 다르면 거부.
- **기초 예상 달성률** = 연간 실적 ÷ 전년 결산단신에 실린 그해 예상. 회사의 보수성 이력.
- 전년 연간 실적 역산(예상 ÷ (1+증감률))은 하지 않는다. 문서로 확인되는 값만 쓴다.

## 8. 범위 밖 (v0.1)

- EDINET API(有報, 半期報告書 본문, 大量保有報告書). v0.2 후보.
- HTML 리포트, 여러 종목 비교, 스크리닝.
- 説明資料 PDF의 想定為替レート, 판매 대수 같은 KPI. "공시 XBRL에 없다"고 말한다.
- 매수·매도·목표가 판단.

## 9. 실패 조건

- 실측 3개 기준(J-GAAP 닌텐도, IFRS 토요타, US GAAP 한 곳)과 업종 3곳(은행, 상사, 게임) 중 하나라도 숫자가 원문과 다르면 출시하지 않는다.
- 누적 숫자를 3개월치로 말하면 실패.
- 출처(링크 또는 금고 sha256) 없이 숫자를 말하면 실패.
- "사도 돼?"에 거절 한 줄로 끝내면 실패.
